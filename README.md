# SeerScore SystemOne Lab

A public, local-first framework for running reproducible SystemOne classification experiments with a private dataset and a human-review UI.

**Privacy by design:** this repository must contain only application code, documentation, tests, and clearly synthetic fixtures. Never commit real SeerScore claims, transcript excerpts, source URLs, private identifiers, outputs, or endpoint settings.

The approved design is in [`docs/superpowers/specs/2026-10-08-seerscoresystemone-design.md`](docs/superpowers/specs/2026-10-08-seerscoresystemone-design.md). The implementation plan is in [`docs/superpowers/plans/2026-10-08-seerscoresystemone.md`](docs/superpowers/plans/2026-10-08-seerscoresystemone.md). Implementation will be staged behind plan review and will not write back to SeerScore.
